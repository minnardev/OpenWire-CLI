**OpenWire CLI** — терминальный саундпад и процессор голосовых эффектов для Linux (PipeWire).

CLI/TUI порт проекта **OpenWire**.

---

## Возможности

### Саундпад
- Сетка 3x5 (15 падов в банке);
- Поддержка банков («Мемы», «Катка», «Стрим»);
- Воспроизведение файлов: MP3, WAV, FLAC, OGG, AAC;
- Режимы воспроизведения: oneshot и loop;
- Раздельная регулировка громкости для наушников и микрофона;
- Остановка всех звуков по клавише Esc.

### Голосовые эффекты
- Pitch Shift и Formant Shift;
- 3-полосный эквалайзер;
- Эффект рации (фильтрация, перегруз, шум);
- Шумоподавление (Noise Gate);
- Ducking: приглушение микрофона при воспроизведении падов;
- Мониторинг: переключатель «Слышать себя».

### Пресеты
- Переключение пресетов клавишей N;
- Сохранение настроек в формате TOML по клавише S;
- Быстрый сброс к чистому голосу по клавише R;
- Совместимость с пресетами OpenWire.

### Мониторинг
- VU-индикаторы входного и выходного уровней;
- Отображение кванта буфера и задержки PipeWire;
- Статус виртуального микрофона `openwire.virtual-mic`.

## Зависимости

- Linux
- PipeWire
- Rust / Cargo

Для Debian / Ubuntu / Kali:
```bash
sudo apt update
sudo apt install -y pkg-config libpipewire-0.3-dev libclang-dev clang
```

Для Arch Linux:
```bash
sudo pacman -S --needed pkgconf pipewire clang
```

---

## Сборка

```bash
cargo build --release
```

Запуск:
```bash
./target/release/openwire-cli
```

Сборка без системного PipeWire (автономный режим):
```bash
cargo build --release --no-default-features
```

## Управление

| Клавиша | Действие |
|---|---|
| **1 .. 5** / **Tab** | Переключение вкладок (Пады, Эффекты, Пресеты, Мониторы, О программе) |
| **Стрелки** | Навигация по падам / параметрам |
| **Пробел** / **Enter** | Воспроизведение / включение |
| **S** | Остановить выбранный пад |
| **Esc** | Экстренная остановка всех звуков |
| **I** | Импорт аудиофайла в пад |
| **B** | Сменить банк |
| **M** | Переключить режим (1-Shot / Loop) или мониторинг |
| **R** | Сброс эффектов к чистому голосу |
| **N** | Следующий пресет |
| **Del** | Очистить пад |
| **Q** | Выход |
