**OpenWire CLI** — легковесный терминальный саундпад (звуковая доска) и процессор голосовых DSP-эффектов реального времени для Linux на базе PipeWire и Ratatui.

Это независимый CLI/TUI порт проекта **OpenWire**, полностью написанный на **чистом Rust** без зависимостей от Tauri, WebKit, Node.js или npm.

---

## Преимущества CLI-порта

- **0% веб-зависимостей**: никакого WebKitGTK, JavaScript или браузерного движка.
- **Минимальное потребление ресурсов**: запуск за доли миллисекунды, мгновенный отклик.
- **Работа в любом терминале**: Alacritty, Kitty, Foot, WezTerm, Tmux или обычная TTY-консоль.
- **Идеально для тайлинговых WM**: i3, Sway, Hyprland, bspwm, dwm.
- **Фирменный дизайн**: оранжевая акцентная тема OpenWire с интерактивным TUI интерфейсом.
- **Полная обратная совместимость**: использует те же пути конфигов (`soundboard.toml`, `settings.toml`, пресеты в `Voices/`), что и настольная версия OpenWire.

---

## Возможности

### 🔊 Саундпад (Звуковая доска)
- Сетка 3x5 (15 падов в каждом банке);
- Поддержка банков («Мемы», «Катка», «Стрим» и пользовательские);
- Воспроизведение звуков: MP3, WAV, FLAC, OGG, AAC;
- Режимы воспроизведения: `oneshot` (однократно) и `loop` (зацикливание);
- Независимая настройка громкости в наушниках и в микрофонный стрим;
- Мгновенная паника: остановка всех звуков одной клавишей (`Esc`).

### 🎙️ DSP-процессор голоса в реальном времени
- **Pitch Shift & Formant**: изменение тональности (-12..+12 полутонов) и формантный сдвиг тембра;
- **3-полосный эквалайзер**: НЧ шельф, параметрический СЧ (частота, усиление, добротность Q), ВЧ шельф;
- **Radio FX**: фильтрация частот рации, насыщение/дисторшн и характерный шумовой фон;
- **Шумоподавление (Noise Gate)**: регулируемый порог отсечки фонового шума;
- **Ducking микрофона**: автоматическое приглушение голоса во время звучания падов;
- **«Слышать себя» (Monitor)**: переключатель прямого мониторинга микрофона в наушники.

### 🎭 Голосовые пресеты
- Переключение пресетов в один клик;
- Встроенные пресеты: «Обычный голос» (сброс эффектов), «Cyberpunk Radio»;
- Сохранение текущих настроек DSP как нового пресета TOML;
- Удаление и просмотр метаданных пресетов.

### 📊 Мониторинг PipeWire
- Живые цветные пиковые VU-индикаторы громкости в реальном времени;
- Отображение текущего кванта (quantum) PipeWire и задержки в миллисекундах;
- Информация об аудиоузлах `openwire.virtual-mic` и `openwire.monitor`.

## Требования

- **Linux** (Arch Linux, Ubuntu, Debian, Fedora, NixOS и др.)
- **PipeWire** (версия 0.3+ / 1.0+)
- **Rust / Cargo** (1.77 или новее)

Для Arch Linux:
```bash
sudo pacman -S --needed base-devel rust pipewire
```

Для Ubuntu / Debian:
```bash
sudo apt update
sudo apt install build-essential cargo libpipewire-0.3-dev libclang-dev
```

Для Fedora:
```bash
sudo dnf install @development-tools rust cargo pipewire-devel
```

## Сборка и запуск

### Быстрый запуск из исходников:
```bash
cd /Users/mark/OpenWire-CLI
cargo run --release
```

### Сборка Arch Linux пакета:
```bash
cd packaging
./build.sh
```

Готовый файл пакета `openwire-cli-*.pkg.tar.zst` появится в каталоге `packaging/`.
Установить его можно командой:
```bash
sudo pacman -U packaging/openwire-cli-*.pkg.tar.zst
```

## Управление клавишами в TUI

| Клавиша | Действие |
|---|---|
| **1 .. 5** / **F1 .. F5** | Переход на вкладку (1: Пады, 2: Эффекты, 3: Пресеты, 4: Монитор, 5: О программе) |
| **Tab** / **Shift+Tab** | Следующая / предыдущая вкладка |
| **Стрелки (↑ ↓ ← →)** | Навигация по падам / параметрам эффектов |
| **Пробел** / **Enter** | Воспроизведение пада / переключение параметра ВКЛ-ВЫКЛ |
| **S** | Остановить воспроизведение выбранного пада |
| **Esc** | **ПАНИКА**: экстренная остановка всех играющих падов |
| **I** | Импортировать аудиофайл в выбранный пад |
| **B** | Переключить текущий аудио-банк |
| **M** | Переключить режим (1-Shot / Loop) или мониторинг голоса |
| **R** | Сбросить все эффекты к чистому голосу («Обычный голос») |
| **N** | Переключить на следующий голосовой пресет |
| **Delete** | Очистить выбранный пад |
| **Q** / **Ctrl+C** | Выход из программы |
